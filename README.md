# KT-7. Master Detail
## Описание
Учебный проект по созданию интерфейса Master-Detail, где "Master" представляет собой список элементов, а "Detail" - детализированное отображение выбранного элемента и реализации интерфейса для просмотра и редактирования информации о пользователях, например, список пользователей и детальная информация о выбранном пользователе.
